# @tempad-dev/site

Vue 3 + Vite app for the Tempad Dev landing page.

## Scripts

- `pnpm dev`
- `pnpm build`
- `pnpm preview`
- `pnpm typecheck`
- `pnpm lint`
- `pnpm lint:fix`
- `pnpm format`
- `pnpm format:check`
- `pnpm test:run` (node and Playwright browser tests)
- `pnpm test:browser`
- `pnpm test:setup` (install Chromium before the first browser test run)
